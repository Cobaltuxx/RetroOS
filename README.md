### *The Ultimate Y2K Computing Experience*

# What is RetroOS?
	
RetroOS is a personal project based on Debian 12 created to bring back the magic of the early 2000s computing era.
It’s not just a skin; it’s a lightweight, functional system built for nostalgia lovers and vintage gamers who want a stable modern base with a classic soul.

# Key Features / Características Clave:
Features
***Classic Desktop***

Customized XFCE environment tuned for that authentic Y2K look & feel.

Escritorio XFCE personalizado con estética original de los 2000.

***Gaming Ready***

Pre-installed emulation tools like RetroArch and DOSBox to jump straight into the action.

Incluye emuladores configurados para jugar desde el primer minuto.

***Modern Stability***	

Built on top of Debian 12, ensuring your old-school experience doesn't crash on modern hardware.

Base sólida de Debian 12 para máxima estabilidad.

***Lightweight***	

Runs smooth even on older machines or limited VMs.

Sistema ultra ligero, ideal para revivir PCs antiguos.
